# Платформа для отслеживания и симуляции торговли валютами

Проект реализован в виде консольного приложения, имитирующего работу валютного
кошелька, и оформлен как пакет Python.

Включает два сервиса:

- Основной Сервис (Core Service): предоставляет
  пользовательский интерфейс (CLI), управляет пользователями, их кошельками,
  журналом действий и взаимодействует с сервисом парсинга для получения актуальных
  курсов валют.
- Сервис Парсинга (Parser Service): по запросу
  или расписанию обращается к публичным API, получает актуальные курсы валют,
  обновляет локальный кэш и сохраняет историю курсов валют в JSON-файл.

## Установка и запуск

Требуются Python 3.12 или новее и uv. Выполняйте команды из корня проекта:

```sh
uv sync
```

Курсы криптовалют загружаются из [CoinGecko](https://docs.coingecko.com/demo/reference/simple-price),
фиатных валют - из [ExchangeRate-API](https://www.exchangerate-api.com/docs/standard-requests).
Перед запуском необходимо указать ключ ExchangeRate-API переменной окружения:

```sh
export EXCHANGERATE_API_KEY="..."
uv run valutatrade
```

Опционально можно указать Demo-ключ для CoinGecko в `COINGECKO_API_KEY`,
без него используется публичный доступ с ограничениями сервиса.

Другие способы запуска: `uv run python main.py` и
`uv run python -m valutatrade_hub`.

## Команды CLI

Команды вводятся в интерактивной консоли после запуска приложения.
Для `buy`, `sell` и `show-portfolio` требуется вход. Остальные команды
доступны без авторизации. Поддерживаются USD, EUR, RUB, BTC и ETH.

В сделках используется полная модель обмена с расчетами в USD.
Сам USD купить или продать нельзя. Перед сделками выполните `update-rates`.

### help - справка по командам

Показывает список команд. Для справки по конкретной команде добавьте `--help`:

```text
help
buy --help
```

### register - регистрация пользователя

Создает пользователя. Обязательные аргументы: `--username` (непустое уникальное
имя) и `--password` (не короче 4 символов). После регистрации выполните `login`.

Новый портфель получает 10 000 USD. Сумма задается параметром
`INITIAL_USD_BALANCE` в `[tool.valutatrade]` файла `pyproject.toml`
и применяется только к новым пользователям.

```text
register --username alice --password 1234
```

### login - вход в систему

Выполняет вход в существующую учетную запись. Обязательные аргументы:
`--username` и `--password`. При каждом запуске приложения вход нужно выполнить
заново; стартовая сумма повторно не начисляется.

```text
login --username alice --password 1234
```

### show-portfolio - просмотр портфеля

Показывает балансы, стоимость каждого кошелька и общую стоимость портфеля.
Необязательный `--base` задает валюту пересчета. Без него используется
`DEFAULT_BASE_CURRENCY` из настроек, по умолчанию USD.

```text
show-portfolio
show-portfolio --base EUR
```

### buy - покупка валюты

Покупает `--amount` единиц валюты `--currency` за USD. Оба аргумента обязательны;
количество должно быть положительным, а USD на покупку должно хватать.
Если кошелька покупаемой валюты еще нет, он создается автоматически.

```text
buy --currency BTC --amount 0.05
```

### sell - продажа валюты

Продает `--amount` единиц валюты `--currency` и зачисляет выручку в USD.
Оба аргумента обязательны; количество должно быть положительным и не превышать
остаток продаваемой валюты.

```text
sell --currency BTC --amount 0.01
```

### get-rate - курс обмена валют

Показывает прямой и обратный курсы обмена валют и время получения в UTC.
Обязательные аргументы: `--from` (исходная валюта) и `--to` (целевая валюта).
Данные берутся из локального кэша без запроса к API.

```text
get-rate --from USD --to BTC
```

### update-rates - обновление курсов валют

Запускает Parser Service и обновляет локальный кэш через API. Без аргументов
опрашиваются оба источника. Необязательный `--source` выбирает один из них:
`coingecko` или `exchangerate`.

```text
update-rates
update-rates --source coingecko
update-rates --source exchangerate
```

Команда показывает число обновленных пар, время обновления и ошибки источников.
При сбое одного API данные второго сохраняются; котировки отказавшего источника
остаются в кэше со старым временем. Если все запросы завершились ошибкой,
файлы с курсами валют остаются прежними.

### show-rates - просмотр курсов валют

Показывает таблицу курсов валют из кэша: валютную пару, курс обмена, время получения
в UTC, источник и статус (`актуален` / `устарел`). Устаревшие значения доступны
для просмотра, но остальные команды их не используют.

Все аргументы необязательны; фильтры можно совмещать:

- `--currency` - показать одну валюту.
- `--top N` - показать N самых дорогих криптовалют; N должно быть положительным целым числом.
- `--base` - валюта пересчета, по умолчанию USD.

```text
show-rates
show-rates --currency BTC
show-rates --top 2
show-rates --base EUR
```

### exit - выход из программы

Завершает работу интерактивной консоли.

```text
exit
```

## Кэш курсов валют

`data/rates.json` хранит последние курсы валют к USD, время получения
и источник каждой котировки. История измерений сохраняется в `data/exchange_rates.json`.
TTL задается параметром `RATES_TTL_SECONDS` в `pyproject.toml` - по умолчанию
300 секунд. Он отсчитывается от получения ответа нашим приложением,
а не от обновления данных у поставщика.

`buy`, `sell`, `show-portfolio` и `get-rate` используют общий кэш курсов валют
без сетевых запросов. Если курс нужной валюты отсутствует или устарел,
выполните `update-rates`. Курс обмена двух валют рассчитывается через USD;
обе котировки должны быть актуальны. При ошибке сделки балансы не меняются.

## Настройки

Параметры приложения задаются в `[tool.valutatrade]` файла `pyproject.toml`.
Если параметр не указан, используется значение по умолчанию:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `USERS_FILE` | `data/users.json` | Файл пользователей |
| `PORTFOLIOS_FILE` | `data/portfolios.json` | Файл портфелей и кошельков |
| `RATES_FILE` | `data/rates.json` | Кэш курсов валют |
| `HISTORY_FILE` | `data/exchange_rates.json` | История курсов валют |
| `INITIAL_USD_BALANCE` | `10_000.0` | Стартовый баланс в USD для новых пользователей |
| `RATES_TTL_SECONDS` | `300` | Срок актуальности курсов валют, в секундах |
| `DEFAULT_BASE_CURRENCY` | `USD` | Базовая валюта для `show-portfolio` без `--base` |
| `LOG_FILE` | `logs/actions.log` | Журнал операций `buy` и `sell` |
| `PARSER_LOG_FILE` | `logs/parser.log` | Журнал обновлений курсов валют |
| `LOG_FORMAT` | `%(levelname)s %(asctime)s %(message)s` | Формат записей в файлах логов |
| `LOG_LEVEL` | `INFO` | Минимальный уровень журнала операций `buy` и `sell` |
| `LOG_MAX_BYTES` | `1_048_576` | Размер файла для ротации, в байтах (по умолчанию 1 МиБ) |
| `LOG_BACKUP_COUNT` | `3` | Количество архивных файлов для каждого журнала |

Парсер пишет в файл сообщения уровня `DEBUG` и выше.

Ключи API задаются через переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `EXCHANGERATE_API_KEY` | Ключ ExchangeRate-API; обязателен для загрузки фиатных курсов валют |
| `COINGECKO_API_KEY` | Необязательный Demo-ключ CoinGecko; без него используется публичный доступ |

Для относительных путей используется рабочая папка.
JSON-файлы создаются во время работы приложения.

## Структура

```text
valutatrade_hub/
    cli/                # console interface
    core/               # models and business logic
    infra/              # configuration and JSON storage
    parser_service/     # exchange rate retrieval and storage
    decorators.py       # trade logging decorator
    logging_config.py   # file logging and rotation
    __main__.py         # package entry point for python -m

data/
    users.json          # users
    portfolios.json     # portfolios and wallets
    rates.json          # latest exchange rate cache
    exchange_rates.json # exchange rate history

main.py
pyproject.toml
uv.lock
```
