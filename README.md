# Платформа для отслеживания и симуляции торговли валютами

Проект реализован в виде консольного приложения, имитирующего работу валютного
кошелька, и оформлен как пакет Python.

Включает два сервиса:

- Основной Сервис (Core Service): предоставляет
  пользовательский интерфейс (CLI), управляет пользователями, их кошельками,
  журналом действий и взаимодействует с сервисом парсинга для получения актуальных
  курсов валют.
- Сервис Парсинга (Parser Service): по запросу
  или расписанию обращается к публичным API, получает актуальные курсы валют,
  обновляет локальный кэш и сохраняет историю курсов валют в JSON-файл.

## Установка и запуск

Требуются Python 3.12 или новее и uv. Выполняйте команды из корня проекта:

```sh
uv sync
uv run valutatrade
```

Другие способы запуска: `uv run python main.py` и
`uv run python -m valutatrade_hub`.

## Команды CLI

Команды вводятся в интерактивной консоли после запуска приложения.
Для `show-portfolio` требуется вход. Остальные команды доступны без авторизации.
Поддерживаются USD, EUR, RUB, BTC и ETH.

Оценка портфеля использует фиксированные курсы из задания.

### help - справка по командам

Показывает список команд. Для справки по конкретной команде добавьте `--help`:

```text
help
register --help
```

### register - регистрация пользователя

Создает пользователя. Обязательные аргументы: `--username` (непустое уникальное
имя) и `--password` (не короче 4 символов). После регистрации выполните `login`.

При регистрации создается пустой портфель.

```text
register --username alice --password 1234
```

### login - вход в систему

Выполняет вход в существующую учетную запись. Обязательные аргументы:
`--username` и `--password`. При каждом запуске приложения вход нужно выполнить
заново.

```text
login --username alice --password 1234
```

### show-portfolio - просмотр портфеля

Показывает балансы, стоимость каждого кошелька и общую стоимость портфеля.
Необязательный `--base` задает валюту пересчета. Без него используется
USD.

```text
show-portfolio
show-portfolio --base EUR
```

### exit - выход из программы

Завершает работу интерактивной консоли.

```text
exit
```

## Структура

```text
valutatrade_hub/
    cli/                # console interface
    core/               # models and business logic
    infra/              # configuration and JSON storage
    parser_service/     # exchange rate retrieval and storage
    __main__.py         # package entry point for python -m

data/
    users.json          # users
    portfolios.json     # portfolios and wallets
    rates.json          # latest exchange rate cache
    exchange_rates.json # exchange rate history

main.py
pyproject.toml
uv.lock
```
